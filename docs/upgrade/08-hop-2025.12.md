## Found on the way

1. **Tag search ids are numbers (app breaks without a fix).**
   - `/tags/filter/search.json` returned `{"id": "wellbeing", "text": "wellbeing"}` up to 3.5. It now returns `{"id": 1, "name": "wellbeing", "text": "wellbeing"}`.
   - The app uses `id` as the tag's name: it shows it, adds it to new posts, and hides `resource` / `non-resource` by it. Tags would show as numbers, and posts would get numeric tags.
   - **Fix in Prose**, branch `fix/tag-search-ids`: hand the app the name as `id`. Tests cover the old and the new shape. Through Prose on 2025.12 the tag search now returns `"wellbeing"` again.
   - Like the login fix, it goes to staging, then production, before the Discourse switch.
   - Topic lists still send tags as names, so only tag search changed.
2. **Inbox lists only received messages.**
   - The ones you start are under Sent.
   - The app is unaffected, because Prose fetches inbox and sent and merges them (checked through Prose).
   - The test data now includes a received message, so check #42 stays strict.
3. **Admin site settings.** One new AI setting (`ai_spam_detection_max_trust_level`) has numeric option names. The app is unaffected: Prose returns all 1,383 settings without errors. Check #91 accepts a number there.
4. **Category `group_permissions` gains `group_id` for admins.** The app only reads `group_name` and `permission_type`. The Layer A test now checks those two fields instead of the exact old shape.
5. **The Mac disk filled up** (131 MB free). Docker's storage went read-only and the install failed with `input/output error`. With Mahmoud's OK, the following were removed, which freed about 11 GB:
   - old robot logs
   - the Hop 1 and plugin-baseline containers and their data
   - the Hop 1 image
   - the merged `discourse-upgrade-plugin` folder
