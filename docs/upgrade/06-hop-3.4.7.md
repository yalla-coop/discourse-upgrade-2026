## Found on the way

1. **Admin sidebar title.** From 3.4.7, a plugin with settings gets its own admin page, titled from `js.<plugin>.title`. The plugin had no client translation, so the label showed raw. Fixed in the plugin (`config/locales/client.en.yml`, commit `82e3a81`). Lexicon has the same gap, which is cosmetic and for admins only.
2. **Lexicon's `llhttp-ffi` gem** failed to build on the first boot of the new container and built fine on retry, so the first `db:migrate` failed. Watch for this at the AWS rehearsal: if a rebuild stops on a Lexicon gem, re-running it is the first thing to try.
3. **Search check #59 failed once** on a freshly seeded database, because the seeded posts were not in the search index yet. Search itself works on 3.4.7: a new post was indexed and found straight away. The seed now indexes its posts (`contract/seed/docker_seed.rb`).
4. **The emulator ran out of storage** while installing the new app build (6 GB data partition, about 365 MB free). Removing the old app build first fixed it. This only affects the local test emulator.
5. Upstream rewrote the chat "while you were away" summary email query in 3.4.x. The plugin still keeps those emails off (`forward_trust_chat_summary_emails`, default off), and Layer A confirms it.
